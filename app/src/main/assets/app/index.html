Bomb Configuration

ℹ️ Note: To change Bomb Duration or Lifeline settings, turn Bomb Mode OFF and ON again. This will reset your current Bomb progress.

Lifeline Settings

You start each day with free Lifelines (0-3, hard max 3). Each study hour interval earns 1 more. Consuming one extends the Bomb Timer by the minutes set above. Everything resets daily.

Default Bomb Duration

Changes take effect after the current Bomb explodes or is reset.

Lifeline

You start each day with the number of free Lifelines set above (0-3, hard maximum 3). Each interval of cumulative Study Pomodoro time (hours set above) earns 1 more. The maximum is permanently fixed at 3 Lifelines per day. Consuming one Lifeline adds the extra minutes above to the Bomb Timer. Everything resets at the start of each new day.

Wake-up Bomb Trigger Behaviour

Choose when Bomb Mode should become active after your Wake-up Time.

About Bomb Challenge Mode

Bomb Challenge Mode keeps you accountable between study sessions. Whenever no productive timer is running, the Bomb Timer counts down. Consuming a Lifeline extends the Bomb Timer with extra minutes. If the Bomb Timer reaches zero with no Lifelines left, the Bomb explodes and your Hour Streak resets to zero. Bomb Challenge Mode is directly linked with the Hour Streak system — completed sessions and history always remain safe.

When Bomb Mode is active, only Start and Stop buttons are available. Pause is disabled because the app supports only one activity at a time.

Project Timeline

This project was created between 6 July 2026 and 8 July 2026. Although it started as a beginner project, it is expected to continue evolving with future updates and improvements.

Motive of Creation

This application was created to help users build long-term consistency instead of relying on motivation. Its primary purpose is to reduce overthinking, encourage disciplined daily action, and make progress measurable through simple, objective tracking.
Rather than focusing only on results, the app rewards consistency through systems such as:
• Daily Goals
• Hour & Day Streaks
• Bomb Challenge Mode
• Lifelines
• Pomodoro-based study tracking
�� Progress History
These features work together to create accountability, maintain momentum, and help users recover from distractions without losing sight of their long-term goals. The app is designed around the philosophy that small, measurable progress repeated every day leads to meaningful long-term improvement.
